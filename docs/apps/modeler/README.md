# Modeler UI

Web-based BPMN modeler for designing and deploying process definitions.

## Status

**Not yet active** — scaffolded but not implemented.

## Planned Features

- BPMN 2.0 diagram editor (based on bpmn.io)
- Form editor (form-js editor)
- Deploy directly to runtime bundle
- Process definition versioning
- Collaboration features

## Technology

| Component | Technology |
|---|---|
| Framework | React 18 |
| Build Tool | Vite |
| BPMN Editor | bpmn-js |
| Form Editor | @bpmn-io/form-js-editor |
